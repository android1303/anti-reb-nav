# Польові тести

- `<YYYY-MM-DD>_<назва>.md` — звіт Архітектора по заїзду (умови, результати, висновки, посилання на TASK). У репозиторії лежать лише ці звіти.
- `data/` — локальна тека для сирих CSV заїздів (для відтворення через `tools/replay/`). Назва: `<YYYY-MM-DD>_<назва>.csv`. У git не потрапляє (`field_tests/data/` і `*.csv` в `.gitignore`): репозиторій публічний, а CSV містять GPS-трек.
