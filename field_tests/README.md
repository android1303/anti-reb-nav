# Польові тести

- `<YYYY-MM-DD>_<назва>.md` — звіт Архітектора по заїзду (умови, результати, висновки, посилання на TASK).
- `data/` — сирі CSV заїздів для відтворення (`tools/replay/`). Назва: `<YYYY-MM-DD>_<назва>.csv`.

Якщо CSV великі або репозиторій публічний — зберігайте їх поза git (наприклад, Google Drive) і вказуйте посилання у звіті.
